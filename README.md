# Feature selection for clinical data

Code for the study "**True Predictor or False Discovery: Evaluating Feature Selection Methods for Trustworthy Discovery in Clinical Data**".


## Contents

- [selection_methods](selection_methods/README.md): includes sample-splitting (single- and multi-split), stability selection (CPSS, IPSS), knockoff (single-realization and derandomized), and heuristic two-stage selections.
- [simulation_framework](simulation_framework/README.md): synthetic data generation
- [cvd_risk_scores](cvd_risk_scores/README.md): CVD risk equations and discrimination metrics.
